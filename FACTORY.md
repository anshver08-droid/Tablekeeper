# Factory Workflow

This repository uses reusable role-based coding mandates for planning,
implementation, and review.

## Roles

- Planner: analyzes requirements and creates an implementation plan.
- Implementer: performs the requested implementation.
- Reviewer: independently reviews the implementation and verification.

## Workflow

1. Inspect the repository and requirements.
2. Plan the requested work.
3. Implement the planned changes.
4. Run tests and validation.
5. Review the resulting implementation.
6. Record relevant verification results.

## Principles

- Preserve existing functionality.
- Make focused, reviewable changes.
- Prefer reproducible verification.
- Do not claim tests or actions that were not actually performed.
- Keep role mandates reusable across projects.
